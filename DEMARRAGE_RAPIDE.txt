ÉTAPE 1: PRÉPARER L'ENVIRONNEMENT
═════════════════════════════════════════════════════════════════════════════

Option A - Windows (Facile)
───────────────────────────
  1. Ouvrir le dossier c:\projet\CCR
  2. Double-cliquer sur "run.bat"
  3. Choisir option "1. Demarrer le serveur"
  ✓ Le serveur démarre à http://localhost:8000

Option B - Ligne de commande
─────────────────────────────
  1. Ouvrir PowerShell/CMD
  2. cd c:\projet\CCR
  3. python manage.py runserver
  ✓ Le serveur démarre à http://localhost:8000


ÉTAPE 2: ACCÉDER À L'APPLICATION
═════════════════════════════════════════════════════════════════════════════

Interface Web
─────────────
  URL: http://localhost:8000

  ├─ Accueil → Tableau de bord avec statistiques
  ├─ Membres → Liste complète avec filtres
  ├─ Statistiques → Tendances et analyses
  ├─ Analyse → Détails par tribu/département
  └─ Administration → Gestion complète


Administration Django
──────────────────────
  URL: http://localhost:8000/admin
  
  Identifiants:
  • Username: admin
  • Mot de passe: [À créer si nécessaire]

COMMANDES UTILES
═════════════════════════════════════════════════════════════════════════════

Arrêter le serveur
──────────────────
  • Windows: Ctrl + C dans la fenêtre du terminal

Vérifier l'installation
───────────────────────
  cd c:\projet\CCR
  python manage.py shell < test_installation.py

Faire une sauvegarde
─────────────────────
  copy db.sqlite3 db.backup.sqlite3

Restaurer une sauvegarde
─────────────────────────
  copy db.backup.sqlite3 db.sqlite3

Effacer toutes les données
───────────────────────────
  cd c:\projet\CCR
  python manage.py shell
  > from eglise.models import *
  > Membre.objects.all().delete()
  > Culte.objects.all().delete()
  > exit()

CONFIGURATION PERSONNALISÉE
═════════════════════════════════════════════════════════════════════════════

Pour modifier la langue:
  Éditer CCR/settings.py
  Chercher: LANGUAGE_CODE = 'fr-fr'

Pour modifier le fuseau horaire:
  Éditer CCR/settings.py
  Chercher: TIME_ZONE = 'UTC'
  Changer en: 'Europe/Paris' (ou autre)

Pour utiliser une autre base de données:
  Éditer CCR/settings.py
  Section DATABASES


MISES À JOUR ET MAINTENANCE
═════════════════════════════════════════════════════════════════════════════

Après modification des modèles:
  cd c:\projet\CCR
  python manage.py makemigrations
  python manage.py migrate

Vérifier la santé du système:
  cd c:\projet\CCR
  python manage.py check

Supprimer la base de données (réinitialiser):
  ⚠️  Attention: Cela effacera toutes les données!
  
  1. Supprimer db.sqlite3
  2. python manage.py migrate
  3. python manage.py createsuperuser
